Química Dorimar es una página E-Commerce de una química distribuidora de productos de Limpieza. El motivo de creación de este proyecto, es para presentar cómo proyecto 
entregable final del curso de JavaScript de Coderhouse.

El contenido de la página se basa en un catálogo con productos de distintas categorías, los cuales pueden ser filtrados por dichas categorías. A su vez que pueden
ser agregados a un carrito, dentro del carrito, el usuario podrá sumar o restar cantidades del producto, así cómo vaciar inmediatamente el mismo o finalizar la compra.
